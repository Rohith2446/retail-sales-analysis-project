# Retail Sales Analysis Project

## Objective
Analyze retail sales data and build a machine learning model to predict total sales.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Features
- Data Cleaning
- Data Visualization
- Correlation Analysis
- Sales Prediction using Linear Regression

## Dataset
Retail Sales Dataset from Kaggle
